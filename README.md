# Scorpia B2B Work Platform

Інтерактивний фронтенд-прототип Scorpia: задачі, план проєкту, база знань, OKR та контекстний AI-помічник.

## Запуск локально

Відкрийте `index.html` у браузері. Збірка, сервер та змінні середовища не потрібні.

## Публікація через GitHub Pages

1. Створіть репозиторій на GitHub і завантажте в нього всі файли цієї папки.
2. Відкрийте **Settings → Pages**.
3. У полі **Build and deployment** виберіть **Deploy from a branch**, гілку `main` та папку `/(root)`.
4. Збережіть налаштування — GitHub надасть публічне посилання за кілька хвилин.

## Функціональність

- Створення, завершення та видалення задач.
- Дані задач зберігаються у браузері через `localStorage`.
- Інтерактивна дошка плану, база знань та OKR.
- Контекстні відповіді AI-демо на основі поточного стану задач.

Це статичний демоінтерфейс. Для спільної роботи в реальному часі, авторизації та справжнього AI потрібен бекенд/API.
